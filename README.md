# ES0008 | TEMA 6: GERENCIADOR DE CURSOS E ALUNOS

### Este programa possui como objetivo facilitar o gerenciamento de cursos em qualquer instituição de ensino ao longo do período acadêmico. É um sistema complexo baseado em linha de comando desenvolvido em Python para o gerenciamento de cursos, turmas, alunos e matrículas, com regras de negócio rígidas como detecção de choque de horários e prevenção de ciclos em pré-requisitos.
